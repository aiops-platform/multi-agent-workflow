# `docs/lessons/` —— 团队共享的教训

**为什么有这个目录**：经验此前只沉在**个人机器**上（Claude Code 的跨 session 记忆是
`~/.claude/...`，队友拿不到）。实测：本机 22 条记忆里 **16 条对全队有效**，而**队友拿到 0 条**。

本目录就是那条通道 —— 配合 `CLAUDE.md` 的「经验索引」，**队友的 Claude Code 不用他知道，
开局就带着这些判据**。

## ⚠️ 先读这条：**这里不是"更多文档"，是"待机器化的清单"**

统计本目录收录的 16 条：**15 条可以写成"如果…就红"的检查**。
也就是说，**绝大部分经验本不该是文档** —— 检查一旦存在，它就**不需要被记住**了。

所以每条都标一个**去向**：

| 去向 | 含义 | 动作 |
|---|---|---|
| ✅ **已机器化** | 检查已存在 | **不需要记**，违反时会红。这里只留指针 |
| 🔴 **待机器化** | 能写成检查但还没写 | **这是本目录的主要产出** —— 逐条转成 test / hook |
| 📄 **只能文档** | 无法写成红绿检查 | 只放这类，且必须带**代价** |

⭐ **判据：一条经验如果在仓库里出现两次，说明它没被机器化。**
（`severity-medium` 与 `status-new` 同族缺 CSS 规则，一天内出现两次 —— 那就是漏掉的信号。）

## 收录标准

一条要进来，必须**同时**满足：

1. **普适** —— 换一台机器、换一个人仍然成立（含本机路径 / 凭证的留在个人的记忆里）
2. **有判据** —— 能写成"遇到 X 就做 Y"，可被 grep、可被判断
3. **有代价** —— 说得出不这么做会看到什么症状

⭐ **没有「代价」的条目不收。** 「`join` 默认 `any`」记不住；
「`rca` 因此**从来没拿到过**五维取证摘要」才记得住。

模板：

```markdown
## <现象，一句话>
**判据**：<遇到 X 就做 Y>
**代价**：<不这么做会出现的具体症状 —— 报错原文 / 错误行为>
**去向**：✅ 已机器化（<检查在哪>） / 🔴 待机器化（<检查该写成什么>) / 📄 只能文档
```

## 怎么持续往里加（**不靠"记录"，靠"回收"**）

要求人在当场"多写一份经验"长期必然烂尾 —— 本仓 134 个 changelog 就是证据。
所以入口**不是**"想到了就写"，而是**回收已经产生的副产品**：

```bash
make retro-harvest SINCE="2 weeks ago"
```

它扫这段时间的**提交信息里的「为什么」**（`CLAUDE.md` 已强制写）、changelog、TODO 新增，
提炼候选并三分类，人只做**点头**，不做回忆与撰写。
